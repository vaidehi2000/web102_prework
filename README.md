# WEB102 Prework - SeaMonster Crowdfunding

Submitted by: **Vaidehi Vaishnav**

SeaMonster Crowdfunding is a dynamic website that displays information about crowdfunded games, including funding statistics, filtering options, and interactive UI elements.

Time spent: **8–10** hours spent in total

## Required Features

The following **required** functionality is completed:

* [x] The introduction section explains the background of the company and dynamically shows how many games remain unfunded.
* [x] The Stats section includes information about the total contributions, total amount raised, and total number of games.
* [x] The top two most funded games are displayed in the Stats section.
* [x] The Our Games section initially displays all games funded by Sea Monster Crowdfunding.
* [x] The Our Games section has three buttons that allow the user to display only unfunded games, only funded games, or all games.

The following **optional** features are implemented:

* [x] Added a search bar to filter games by name (and description) in real time.
* [x] Added basic styling for the search input field.

## Notes

One of the main challenges was working with JavaScript array methods like `filter` and `reduce` to dynamically update the UI. Ensuring that the DOM updates correctly without duplicating elements required careful handling, especially when switching between filters.

Implementing the search functionality was a useful addition that made the app feel more interactive and closer to a real-world product.
